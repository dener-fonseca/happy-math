O que é divisão?

A divisão é uma operação matemática usada para repartir uma quantidade em partes iguais.

Quando dividimos, queremos descobrir quanto cada pessoa ou grupo receberá quando uma quantidade é distribuída igualmente.

O símbolo usado para representar a divisão é o ÷, chamado de sinal de divisão.

Por exemplo, imagine que temos 6 maçãs e queremos dividi-las igualmente entre 2 crianças.

Podemos repartir as maçãs igualmente:

👧 🍎🍎🍎

👦 🍎🍎🍎

Cada criança recebe 3 maçãs.

Então podemos representar essa divisão assim:

6 ÷ 2 = 3

A divisão permite descobrir quanto cada grupo receberá quando uma quantidade é repartida igualmente.

Como fazer a divisão?

Para fazer uma divisão, precisamos repartir uma quantidade igualmente entre os grupos ou pessoas.

Imagine que existem 12 maçãs e elas serão divididas igualmente entre 3 crianças.

Primeiro, temos as 12 maçãs:

🍎🍎🍎🍎🍎🍎🍎🍎🍎🍎🍎🍎

Agora precisamos distribuir as maçãs de maneira que todas as crianças recebam a mesma quantidade.

Podemos repartir assim:

👧 → 🍎🍎🍎🍎

👦 → 🍎🍎🍎🍎

👧 → 🍎🍎🍎🍎

Ao final, cada grupo recebeu 4 maçãs.

Podemos representar essa situação usando uma conta:

12 ÷ 3 = 4

Nessa conta, o 12 é a quantidade que será dividida, o 3 representa a quantidade de grupos e o 4 é o resultado, ou seja, a quantidade que cada grupo recebeu.

Então, quando fazemos uma divisão, repartimos uma quantidade em partes iguais para descobrir quanto ficará em cada grupo.
