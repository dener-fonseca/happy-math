Como funciona a comparação de números?

Comparar números significa observar dois ou mais números para descobrir qual deles é maior, qual é menor ou se eles são iguais.

Podemos comparar números pensando nas quantidades que eles representam.

Por exemplo, o número 8 representa uma quantidade maior do que o número 5.

8 > 5

Isso significa que 8 é maior que 5.

Maior que

Quando um número representa uma quantidade maior do que outro, usamos o símbolo >.

O símbolo > significa maior que.

Observe:

7 > 4

Podemos ler essa comparação assim:

7 é maior que 4.

Isso acontece porque 7 representa uma quantidade maior do que 4.

Menor que

Quando um número representa uma quantidade menor do que outro, usamos o símbolo <.

O símbolo < significa menor que.

Observe:

3 < 8

Podemos ler essa comparação assim:

3 é menor que 8.

Isso acontece porque 3 representa uma quantidade menor do que 8.

Igualdade

Quando dois números representam a mesma quantidade, usamos o símbolo =.

O símbolo = significa igual a.

Observe:

6 = 6

Podemos ler essa comparação assim:

6 é igual a 6.

Os dois números possuem o mesmo valor, por isso usamos o sinal de igualdade.

Dica

Uma maneira fácil de lembrar dos símbolos > e < é imaginar uma boca.

A boca fica sempre aberta para o número maior.

9 > 2

2 < 9
