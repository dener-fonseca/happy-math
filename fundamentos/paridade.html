Paridade dos Números

Página Inicial

O que é paridade dos números?

A paridade é uma característica que permite identificar se um número é par ou ímpar.

Essa identificação pode ser feita observando o último algarismo do número.

Os números que terminam em 0, 2, 4, 6 ou 8 são pares.

2, 4, 6, 8, 10, 12, 24, 38...

Já os números que terminam em 1, 3, 5, 7 ou 9 são ímpares.

1, 3, 5, 7, 9, 11, 25, 37...

Números pares

Um número é par quando pode ser dividido em duas partes iguais, sem deixar nenhuma unidade sobrando.

Observe o exemplo:

8 → 4 + 4

O número 8 pode ser separado em dois grupos com 4 unidades em cada um. Por isso, 8 é um número par.

Outros exemplos de números pares são:

0, 2, 4, 6, 8, 10, 12, 14...

Números ímpares

Um número é ímpar quando não pode ser dividido em duas partes iguais sem que uma unidade fique sobrando.

Observe o exemplo:

7 → 3 + 3 + 1

Podemos formar dois grupos com 3 unidades, mas uma unidade sobra. Por isso, 7 é um número ímpar.

Outros exemplos de números ímpares são:

1, 3, 5, 7, 9, 11, 13...

Como descobrir a paridade de um número?

Para descobrir se um número é par ou ímpar, basta observar o seu último algarismo.

Por exemplo:

42

O último algarismo é 2. Como 2 está entre 0, 2, 4, 6 e 8, podemos concluir que 42 é par.

Agora observe:

35

O último algarismo é 5. Como 5 está entre 1, 3, 5, 7 e 9, podemos concluir que 35 é ímpar.

Dica

Você não precisa observar todos os algarismos. Para descobrir a paridade de um número, basta olhar para o último algarismo.
