O que são medidas?

As medidas são usadas para descobrir o tamanho, a quantidade ou a capacidade de alguma coisa.

Usamos medidas em várias situações do nosso dia a dia.

Por exemplo, podemos medir:

  • o comprimento de uma mesa;
  • o peso de uma pessoa;
  • a quantidade de água em uma garrafa;
  • o tamanho de uma parede;
  • a quantidade de ingredientes de uma receita.

Para cada tipo de medida, usamos unidades de medida diferentes.

Medidas de comprimento

As medidas de comprimento são usadas para descobrir o tamanho ou a distância entre objetos ou lugares.

Algumas unidades de comprimento são:

  • milímetro (mm)
  • centímetro (cm)
  • metro (m)
  • quilômetro (km)

Usamos o centímetro, por exemplo, para medir objetos pequenos, como um lápis.

O metro pode ser usado para medir objetos maiores, como uma porta ou uma parede.

O quilômetro é usado para medir distâncias maiores, como a distância entre duas cidades.

Exemplos:

✏️ Lápis → centímetros

🚪 Porta → metros

🛣️ Distância entre cidades → quilômetros

Medidas de massa

As medidas de massa são usadas para descobrir quanto algo pesa.

As unidades mais conhecidas são o grama (g) e o quilograma (kg).

Usamos o grama para medir objetos que possuem pouca massa.

O quilograma é usado para medir objetos ou quantidades mais pesadas.

Por exemplo:

🍬 Um pacote pequeno → gramas

🍉 Uma melancia → quilogramas

Quando vamos ao mercado, é comum encontrar produtos que indicam sua massa em gramas ou quilogramas.

Medidas de capacidade

As medidas de capacidade são usadas para descobrir quanto líquido cabe em um recipiente.

As unidades mais conhecidas são o mililitro (mL) e o litro (L).

Usamos o mililitro para pequenas quantidades de líquido.

O litro é usado para quantidades maiores.

Por exemplo:

🥄 Remédio → mililitros

🧃 Caixa de suco → litros

Assim, podemos escolher a unidade de medida de acordo com aquilo que queremos medir.
